# The Winter Edit

Interactive Italy and Switzerland trip planner for five friends, 27 December 2026 to 8 January 2027.

Live site: https://amcs1729.github.io/winter-trip/

Top-down route map, day editors, accommodation shortlist, editable budget, local saving, JSON export/import and print/PDF. No build step required.

Planning estimate: INR 259,210 per person including 15% contingency. International flights, visas and shopping excluded. Exact-date accommodation availability and prices remain unconfirmed.

Country boundaries: Natural Earth (public domain). Photos: Unsplash. Fonts: Google Fonts.
